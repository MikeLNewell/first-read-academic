Built-in boundaries

Privacy & safeguards

Useful automation without pretending academic judgement has been automated.

01

No automated mark

The prompt explicitly prohibits percentages, classifications and pass/fail decisions.

02

No AI-authorship claims

The system is told not to decide whether generative AI was used or allege misconduct.

03

Brief-bound analysis

The model is instructed to use only the lecturer-supplied assessment context and evidence in the submission.

04

No student-file storage

The submission is sent to the serverless review function and is not written to the assessment database or browser storage by this app.

05

Persistent briefs only

Assessment profiles are stored separately in Supabase so annual briefs and rubrics remain available across devices and redeployments.

06

Human approval

Every feedback field is editable. Export is a lecturer action, not an automatic release to the student.

Before live student use

Seek confirmation from your institution's data protection / information governance team, complete any required DPIA, and confirm the approved OpenAI API configuration and retention controls. This remains a technical prototype until institutionally approved.
